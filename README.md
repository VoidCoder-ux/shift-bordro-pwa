# Shift Bordro PWA

Tek kullanicili shift ve bordro hesaplama uygulamasi. GitHub Pages uzerinde calisir, verileri tarayicida saklar ve offline acilir.

## Komutlar

```bash
npm install
npm run dev
npm run test
npm run build
```

## Bordro varsayimlari

- Gunluk standart sure: 7.5 saat
- Aylik standart sure: 225 saat
- SGK isci primi: %14
- Issizlik primi: %1
- Damga vergisi: %0.759
- Referans kalibrasyon: Ocak 2026 bordrosu, brut 55.528,63 TL ve net 44.160,00 TL

Uygulama resmi bordro yerine gecmez; calisanin kendi vardiya ve net maas takibi icin tasarlanmistir.
